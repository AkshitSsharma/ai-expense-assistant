# 💰 Hanks AI Expense Assistant

AI-powered expense tracker using **voice input, LLMs, and data analytics** to simplify personal finance.

---

## 🚀 Features
- 🎤 Voice-based expense logging (natural language → structured data)
- 🧠 LLM-powered extraction (amount, category, date)
- 📊 Live dashboard with charts & insights
- 💰 INR-based financial tracking

👉 **Live App:** https://your-app.streamlit.app

---

## 🛠️ Tech Stack
Python • Streamlit • OpenAI API • SQLite • Pandas • Matplotlib

---

## ▶️ Run Locally
```bash
pip install -r requirements.txt
python app.py          # voice assistant
streamlit run dashboard.py   # dashboard
